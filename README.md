# ☕ The Swadeshi Cafe - Responsive Web Design (HTML & CSS)

A visually appealing, modern, and fully responsive multi-page website built for **The Swadeshi Cafe**. This project focuses on clean page layout, custom CSS styling, smooth hover effects, and standard web UI design practices.

---

## 🚀 Features

- 🏠 **Multi-Page Layout**: Seamless navigation across Home, Menu, and Table Booking pages.
- 🎨 **Custom CSS Styling**: Beautiful color scheme, rounded cards, depth shadows, and clean typography.
- 📊 **Styled Menu Table**: Elegantly designed table presenting cafe items, categories, and pricing.
- 📝 **Interactive Form Controls**: Customized input fields, date/time pickers, and submission buttons.
- 📱 **Responsive Design**: Optimized to look great on both desktop and mobile devices.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic elements, forms, tables, and page links.
- **CSS3**: Custom layouts, color palettes, box shadows, border styling, and hover states.
